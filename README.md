# Railway Design Level Calculator

A MATLAB App Designer application developed to automate railway design-level calculations.

## Purpose

The application calculates design levels for railway construction layers, including:

- Subgrade
- Sub-ballast

It uses chainage, offset, base level, layer thickness and cross-slope information to reduce repetitive manual calculations.

## Current features

- Selection of different railway sections
- Loading of section-specific engineering databases
- Chainage and offset processing
- Subgrade and sub-ballast calculations
- Input-file validation
- Export of calculated results

## Technology

- MATLAB
- MATLAB App Designer

## Project status

This application is under active development. Calculated results should be independently verified before being used for engineering or construction work.
